# ⚙️ Laser Cut Projects

## 📖 About
This repository contains mechanical designs created for laser cutting.

The projects focus on acrylic parts and functional structures.

## 📂 Projects Included
- Acrylic box design  
- Custom mechanical parts  

## 🛠️ Tools Used
- CAD Software  
- Due Studio (Laser Cutting)

## ⚡ Manufacturing Notes
Parameters such as power and speed are adjusted based on material thickness.
